Cómo instalar NFC Pay en Android

  1. Descarga el archivo APK con el botón de arriba.
  2. Abre el archivo descargado en tu teléfono Android.
  3. Si Android solicita autorización para esta fuente, habilítala únicamente si confías en el archivo.
  4. Instala y abre NFC Pay. Activa NFC para probar su detección y utiliza los cobros simulados.
Aviso importante: NFC Pay está en fase de prueba. El estado «NFC activado» no significa que el dispositivo esté certificado para aceptar pagos bancarios. No acerques tarjetas esperando cobros reales. No introduzcas números de cuenta ni datos sensibles.
